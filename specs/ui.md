# recruit-flow UI 스펙

2026-07-24 grill-me 세션(Q2~Q9)으로 확정. 상위 문서:
[recruit-flow-blueprint.md](../recruit-flow-blueprint.md). 본문에서 "결정
N"은 블루프린트 결정 요약 번호를 가리킨다.

## 1. 최상위 레이아웃 — 탭 기반 SPA + 4존 (Q2·Q3)

사용자 체감은 **한 화면**. 페이지 이동 없이 상단 탭으로 컨텐츠 영역만
교체한다(Next App Router 클라이언트 네비게이션 — URL은 바뀌므로
새로고침 복원·북마크 가능).

```
┌──────────────────────────────────────────────────┐
│ 상단 바: [캔버스] [문서] 탭 · 파이프라인 드롭다운    │
│          · Run 버튼 · run 히스토리 드롭다운          │
├──────────────────────────────────────────────────┤
│ 탭 컨텐츠 영역                                     │
│  · 캔버스 탭(/pipelines/[id]):                     │
│    ┌────────┬─────────────────────┬─────────┐     │
│    │ 팔레트  │  React Flow 캔버스   │ 사이드   │     │
│    │        │                     │ 패널     │     │
│    └────────┴─────────────────────┴─────────┘     │
│  · 문서 탭(/documents):                            │
│    문서 목록 + 마크다운 편집기 + 버전 히스토리        │
├──────────────────────────────────────────────────┤
│ 채팅 독 (하단 전폭, 두 탭 모두에서 유지)             │
└──────────────────────────────────────────────────┘
```

- **상단 바와 채팅 독은 공유 레이아웃** — 탭을 오가도 유지된다. 캔버스
  상태는 Zustand에 있어 문서 탭에 다녀와도 그대로.

### 패널 리사이즈 (Q9a)

접힘/펼침에 의존하지 않는다 — **모든 패널 경계는 드래그
리사이즈**: 팔레트 폭, 사이드 패널 폭, 채팅 독 높이, 문서 탭의 문서
목록·버전 히스토리 폭을 분할선 드래그로
자유롭게 조절. 팔레트·사이드 패널은 창 폭의 절반 이상(최대
55vw)까지 넓힐 수 있다 — 팔레트에서 블록 상세를 넉넉히 보거나
아티팩트를 넓게 읽는 용도. 사이드 패널 내부의 [속성]/[아티팩트] 탭
구조는 유지.
레이아웃은 반응형(창 크기 변화 시 캔버스가 남는 공간을 흡수)이고, 패널
크기는 localStorage에 보존해 재방문 시 복원한다. 채팅 독 접기(한 줄
입력바)와 사이드 패널 접기는 보조 수단으로 남긴다.

### 라우트

| 라우트 | 내용 |
| --- | --- |
| `/pipelines/[id]` | 캔버스 탭(작업실 본체). 앱 진입 시 마지막 파이프라인으로 리다이렉트 |
| `/documents` | 문서 탭 — 라이브러리 + 편집기 + 버전 히스토리. **M1 포함**(M1에서 JD·증거를 넣는 유일한 수단) |

- 파이프라인 전환/생성: 상단 바의 파이프라인 이름 클릭 → 드롭다운(목록
  + "새 파이프라인"). 화면 구조는 유지, 캔버스·채팅만 교체.
- run 히스토리: 상단 바 드롭다운. 과거 run 선택 시 캔버스가 **읽기 전용
  스냅샷 모드**로 전환(애니메이션 없음, "현재로 돌아가기" 배지 표시).

## 2. 캔버스 — 노드·엣지 시각 언어 (Q4)

2계층(결정 4)을 **방향으로 분리**한다: 실행 흐름은 가로, 장착은 세로.

### 실행 계층 (Agent / Input / Output / Gate / Human)

- 카드형 노드. 좌측 핸들 = 입력, 우측 핸들 = 출력. **실선 엣지**.
- 카드 구성: 타입 아이콘 + 색 배지(헤더) / 노드 이름 / 한 줄
  요약(Agent=역할, Gate=조건식) / 하단 상태 표시.
- Gate는 마름모 느낌의 변형 카드(분기 시맨틱). Human은 사람 아이콘,
  대기 시 점멸(결정 9).

### 장착 계층 (Skill / Rule / Tool)

- 작은 **알약(pill)형** — 카드보다 확실히 작게.
- 상/하 핸들로 Agent 카드 상단 핸들에 **점선 엣지** 연결.
- Rule 1개 → Agent 여럿 공유 장착은 점선 다중 갈래로 자연 표현.
- (기각한 대안: Agent 카드 안 칩 목록 — 공유 장착이 안 보이고 레고
  컨셉이 약해짐)

### 실행 상태 색

| 상태 | 표현 |
| --- | --- |
| 대기 | 회색 |
| 큐 대기 | 노랑 |
| 실행 중 | 파랑 — 테두리 애니메이션 + 엣지 흐름 애니메이션 |
| 성공 | 초록 |
| 실패 | 빨강 |
| Human 대기 | 주황 점멸 |

과거 run 스냅샷 모드에서는 애니메이션 없이 최종 색만.

## 3. 사이드 패널 (Q5)

탭 2개: **[속성] / [아티팩트]**.

### [속성] 탭 — 노드 타입별 폼, 기본/고급 2단 (Q9d)

사용자가 굳이 바로 편집할 필요 없는 필드는 접힌 **"고급 설정 ▾"**
안에 숨긴다. 기본 영역만 보이는 상태가 직관적 기본값.

| 노드 | 기본 | 고급 설정 ▾ |
| --- | --- | --- |
| Agent | 이름 · 역할(시스템 프롬프트, 문서 id 포인터 삽입 지원) · 출력 형식(마크다운/JSON 선택만) · 장착된 Skill/Rule/Tool 목록(읽기 전용 — 배선은 캔버스에서) | 모델 선택 · JSON 스키마 편집기 · 갭 인터뷰 모드(멈추고 묻기 / `[확인 필요]` 계속, 결정 9b) |
| Input | 문서 선택 드롭다운(문서 라이브러리 연동) | 인라인 텍스트 모드 |
| Output | 템플릿 선택(1~2종) | 파일명 규칙 |
| Gate | 조건식 편집기(예: `score >= 8`) | 실패 시 라우팅(재시도 대상 노드 / 중단) · 최대 루프 횟수 |
| Human | 지시문(사람에게 보여줄 안내) | 편집 허용 여부 |

- 편집은 **실행 중에도 허용** — run은 스냅샷(결정 9b)이라 충돌 없음.
  "다음 run에 반영됩니다" 배지만 표시.

### [아티팩트] 탭

- 선택한 run(기본 최신)에서 이 노드가 낸 아티팩트.
- 마크다운 = 렌더링 뷰(원문 토글) / JSON = 구조화 뷰(점수·PASS/FAIL
  하이라이트).
- 실행 중이면 스트리밍 실시간 추가(결정 6).
- Human 노드 아티팩트는 **직접 편집 가능 + [승인] 버튼** — 채팅 카드와
  동일 동작의 양방향 진입점.
- 루프로 한 run에서 여러 번 실행된 노드는 회차 선택 칩.

### 최종 이력서 다운로드

**Output 노드가 주 다운로드 경로 (M1부터)**: Output 노드 성공 시 노드
카드에 `⬇ HTML` 버튼이 나타나고, 노드 클릭 시 [아티팩트] 탭이
**렌더링 미리보기 + [HTML 다운로드] 버튼**을 보여준다. 채팅 run 완료
카드의 [HTML 다운로드]는 보조 경로(M2부터). 과거 run의 이력서는 run
히스토리 드롭다운 → 해당 run 선택 → Output 노드 클릭으로 동일하게
받는다.

## 4. 채팅 독 (Q6)

- **파이프라인당 1개 영속 스레드**(DB 저장, 새로고침 복원). 블록 제작
  대화 + run 이벤트 카드가 시간순 한 스트림(결정 9).
- 파이프라인 전환 시 채팅도 해당 스레드로 교체.

### 메시지 타입 5종

| 타입 | 내용 |
| --- | --- |
| 사용자 텍스트 | 일반 입력. "작성해줘" = 실행 트리거(결정 9b) |
| 챗봇 응답 | 스트리밍 텍스트 |
| 블록 생성 카드 | 챗봇이 add한 블록 미리보기 + "새 블록 트레이에 담김". 카드에서 트레이 위치 하이라이트 점프 |
| Human 대기 카드 | 노드 지시문 + 아티팩트 첫 줄 요약 + [사이드 패널에서 열기] / [승인]. 갭 인터뷰는 이 카드의 변형 — 질문 + 인라인 답변 입력창 |
| run 보고 카드 | run 시작/완료/실패, 게이트 실패 보고(점수·사유·루프 회차). 완료 카드엔 [HTML 다운로드] |

- 캔버스의 점멸 Human 노드 클릭 → 채팅 독 펴지며 해당 카드로
  스크롤(결정 9 양방향 연결).

### 마일스톤 매핑

- M1: 독 자체를 숨김.
- M2: 챗봇 없는 **이벤트 스트림**으로 등장(run 보고·Human 대기 카드 —
  Human 노드가 M2 소속이므로).
- M3: 입력창 활성화, 사령탑 완성.

## 5. 팔레트 (Q7)

**2계층 트리 + 새 블록 트레이 (Q10-B)**: 별도의 "블록 라이브러리"
구획 없이, 저장된 정의는 자기 타입 아래에 소속된다.

```
┌─ 팔레트 ──────────────┐
│ 기본 블록 (트리)        │
│  ▾ Agent              │  ← 타입 클릭 = 하위 항목 펼침
│     · 빈 Agent         │  ← 새로 만들기용
│     · 이력서 작성자 [on] │  ← 저장된 정의 (M2 임포터가
│     · 비평가     [on]  │     기존 에이전트 16종을 이관)
│  ▸ Input / Output /   │
│    Gate / Human /     │
│    Skill / Rule / Tool│
│ ▾ 새 블록 트레이        │  챗봇이 add한 블록 (결정 5)
└───────────────────────┘
```

- 각 타입의 첫 하위 항목은 **빈 블록**(새로 만들기), 그 아래에 저장된
  정의들. 항목이 많아지면 트리 상단에 검색창(M2).
- **클릭·더블클릭 관용구 (Q9b·Q10)** — 명시적 버튼 없이 UI에 녹인다:
  - **타입 행 클릭** = 하위 항목 펼침/접힘.
  - **하위 항목 드래그** = 캔버스에 추가(주 동선).
  - **하위 항목 더블클릭** = 캔버스 빈자리에 자동 배치 추가(드래그의
    클릭 대안). 추가된 노드는 잠시 하이라이트, 배선은 사람이.
  - **하위 항목 클릭** = 상세 팝오버 — 블록 설명 2~3줄 + "더블클릭
    또는 드래그로 추가" 힌트. 조작 버튼은 없음.
- **활성/비활성 = 도구상자 큐레이션, 하위 항목별 토글**: 각 하위 항목
  행에 hover 시 작은 토글이 나타나고(비활성 상태면 상시 노출), 항목별
  개별 on/off. 비활성 항목은 흐려지고 드래그·더블클릭 추가 불가.
  이미 캔버스에 있는 노드에는 영향 없음. 지금 안 쓰는 블록을 치워
  팔레트를 단순하게 유지하는 용도.
- **드래그 시맨틱 = 템플릿 복사**: 라이브러리 블록 드래그 → 정의의
  독립 사본으로 노드 생성. 이후 수정은 원본·다른 노드에 영향 없음.
  (참조 공유는 "저기 고쳤더니 여기가 바뀜" 예측 불가 → 기각. 정의
  업데이트 일괄 전파는 v2)
- 캔버스에서 다듬은 노드는 우클릭 **"라이브러리에 저장"**으로 역승격.
- **새 블록 트레이 생애주기**: 챗봇 add → 트레이 입고 → 캔버스로 드래그
  = 승인(결정 5) + 라이브러리 저장 + 트레이에서 제거. 트레이에서 X =
  거절(폐기). 트레이 개수는 팔레트가 접혀도 배지 표시.
- **항목 우클릭 = 컨텍스트 메뉴(Notion 식)**: 팔레트 항목을 우클릭하면
  그 항목에 대한 작업 메뉴가 커서 위치에 뜬다. 클릭·드래그·더블클릭에
  이미 있는 동선을 메뉴로도 노출해 발견성을 높이고, UI에 없던 이름 변경·
  삭제 동선을 여기서 제공한다. 섹션마다 항목이 다르다:

  | 항목 종류 | 메뉴 항목 |
  | --- | --- |
  | 빈 블록(blockDef 없음) | 캔버스에 추가 |
  | 저장된 정의(라이브러리) | 캔버스에 추가 · 활성/비활성 토글 · 이름 변경 · 삭제 |
  | 새 블록 트레이 | 승인하고 추가 · 이름 변경 · 거절(폐기) |

  (활성/비활성 토글은 저장된 정의에만 의미가 있다 — 빈 블록은 항상
  쓸 수 있는 템플릿이라 큐레이션 대상이 아니다. §5 본문의 활성/비활성
  규칙과 정합.)

  - **캔버스에 추가** = 더블클릭과 동일(빈자리 자동 배치). **승인하고
    추가** = 드래그 승인과 동일(라이브러리 저장 `tray:false` + 캔버스
    추가 + 트레이 제거). 라벨로 의미 차이를 드러낸다.
  - **이름 변경** = 인라인 편집: 행 이름이 입력창으로 바뀌고 Enter·
    포커스 이탈로 저장, Esc로 취소. 저장된 정의·트레이 항목만 대상
    (빈 블록은 이름 고정).
  - **삭제**(라이브러리)·**거절**(트레이)은 되돌릴 수 없으므로 앱 자체
    **확인 팝업**을 거친다(브라우저 `confirm` 아님). 기존 트레이 X 버튼도
    같은 확인을 거쳐 일관성을 맞춘다.
  - **비활성 항목** 우클릭: 메뉴는 뜨되 "캔버스에 추가"는 비활성 표시
    (드래그·더블클릭 추가 불가 규칙과 정합), 토글은 사용 가능.
  - 우클릭 시 열려 있던 상세 팝오버는 닫는다(동시 표시 금지). 메뉴는
    바깥 클릭·Esc·항목 실행 시 닫힌다. 뷰포트 가장자리에서 잘리지 않게
    위치를 보정한다. 브라우저 기본 컨텍스트 메뉴는 팔레트 항목 위에서만
    억제한다.
- 마일스톤: M1은 트리에 빈 블록만(그중 Agent/Input/Output 3종 활성),
  저장된 정의 하위 항목·검색은 M2, 트레이는 M3. 항목 컨텍스트 메뉴는
  M3 이후 추가.

## 6. 툴팁 — 전역 규칙 (Q9c)

모든 팔레트 항목, 속성 필드 라벨, 상단 바 버튼에 hover 툴팁(0.5초
지연): 제목 + 2~3줄 상세 설명. UI에 설명 텍스트를 상시 노출하지 않고
툴팁으로 밀어, 화면은 직관적으로 단순하게 유지한다(Q9d의 고급 설정
분리와 같은 원칙).

## 7. 상단 바 실행 제어 (Q8)

### Run 버튼 상태

| 상태 | 표시 |
| --- | --- |
| 대기 | `▶ 실행` — 클릭 시 그래프 검증(고아 노드·사이클·Output 부재 경고) 후 run 시작(스냅샷 생성) |
| 실행 중 | `■ 중단` + 진행 `3/7 노드`. 중단 = 현재 노드 SDK 호출 취소, run을 `cancelled` 기록(아티팩트는 거기까지 보존) |
| Human 대기 | 진행 표시가 `사람 대기 중` 주황 배지 |

### 부분 재실행 (M2)

- 노드 우클릭 → **"이 노드부터 재실행"**: 새 run 생성, 상류 아티팩트는
  **직전 완료 run에서 복사** 재사용, 해당 노드부터 하류만 실행.
- 재사용 출처 선택 UI는 v2.
